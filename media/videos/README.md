# Video Demonstrations

Place video recordings (`.mp4`, `.mov`, `.mkv`) of the Waveshare UGV02 autonomous navigation and SLAM mapping in this directory.

### Recommended Demos:
1. `mapping_demo.mp4` - Teleoperation through the room with live SLAM Toolbox map generation in Foxglove Studio.
2. `navigation_demo.mp4` - Point-and-click goal navigation in Foxglove with smooth MPPI trajectory tracking and obstacle avoidance.
